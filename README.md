## 🌟 Project Overview

This repository contains the complete source code for **Mini Project 1: Personal Portfolio Website**, developed as part of the **Web Technologies** course curriculum.

The website is a responsive, single-page personal portfolio built exclusively with **pure HTML5 and CSS3** (without any JavaScript or third-party CSS frameworks like Bootstrap or Tailwind). It showcases academic qualifications, technical skills, full-stack projects, research contributions, and contact details with a refined medium-mode design aesthetic.
